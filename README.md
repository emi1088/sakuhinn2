## 📌 プロジェクト概要

本プロジェクトは、実店舗ネイルサロンの新規顧客獲得およびリピーターによる紹介・新規顧客増加を目的としたWebサイトのリニューアルプロジェクトです。  
既存客・新規客双方にとって「おしゃれで行ってみたい」「レビューが多くて安心して予約できる」と感じられる、信頼性とデザイン性を両立したUI/UXを目指しました。

---

## 🎯 ターゲット & ユーザーシナリオ

### ターゲット（ペルソナ）
* **20代〜40代の働く女性・トレンドやおしゃれに敏感な方**
* 多忙な日々の中で、自分へのご褒美や癒やしを求めている方

### ユーザーシナリオ
1. **発見・興味**: 洗練されたWebサイトのデザインを見て「おしゃれで綺麗だから行ってみたい！」と感じる。
2. **検討・安心**: 豊富なレビューやリアルなサロンの雰囲気を参考に、自分に合いそうかを確認。
3. **行動（コンバージョン）**: 安心してスムーズに予約へ進む。

## 💡 工夫したポイント・主な機能

* **ビジュアル重視の構成**: サロンの雰囲気や施術デザインが直感的に伝わるビジュアル配置。
